# English Words

Флешкартки для вивчення англійських слів. Один файл `index.html`, усе працює в браузері, дані у `localStorage`.

- **Вчити** — картка зі словом, тап показує переклад. `Знаю` — слово більше не показується, `Не знаю` — повернеться через кілька карток.
- **Словник** — пошук, додавання слова вручну, зняти/поставити позначку «вивчено», видалення.
- **Меню** — імпорт CSV (файл або вставлений текст), експорт CSV, напрямок картки, скидання прогресу.

CSV формат: `word; переклад` (один рядок — одне слово). Базовий список із `words.csv` вшитий у сторінку і завантажується при першому відкритті.
